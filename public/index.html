16 MCP tools · read-only game access

Focused tools for characters, markets, skill planning, and maps, plus a searchable catalogue of ESI operations. Your assistant can find an operation, inspect its inputs, and request the data. Public EVE data needs no login; protected data requires EVE character consent.

Universe & SDE 03

Find your way through New Eden. Resolve places and items, plan complete routes and pickup loops, and render maps from static universe data.

How routes and maps work +

Resolve exact EVE entity names and IDs, and check the published static-data build. Use plan_eve_route for complete routes and pickup loops: the server computes shortest paths, stop order and totals. Pass its routeId directly to the map renderer. Crowded maps use a larger padded canvas; if a map cannot be drawn readably, the route remains available as text. Raw route arrays are rejected. Context maps take an explicit boundary and points of interest (POIs, or an empty list). Request a neighborhood boundary with an exact system name or numeric ID as center for that system and all its incoming/outgoing permanent-stargate neighbors. jumps defaults to 1; only 1 is supported, with a 250-system limit and no ESI discovery chain needed. Routing uses static permanent stargates, makes no ESI calls and needs no EVE login. The assistant explains tool results and never calculates or redraws a route.

03

Your next conversation starts here.

npm package · local MCP server

  1. 01

    Prepare your MCP client

    Install Node.js 22.13.0 or newer and use an MCP client that can launch local servers over stdio. The eve-online-mcp package includes the EVE tools, resources, and prompts.

  2. 02

    Add the server configuration

    Configure your client to run npx with arguments -y eve-online-mcp, then reconnect it. The example uses the common mcpServers format; check your client’s configuration instructions.

  3. 03

    Ask about New Eden

    Start with public markets or universe data. When you request protected character data, the default setup opens EVE SSO in your browser so you can choose the character and approve access.

04

A few things to know.

Is it read-only?+

Game data access is read-only: the catalog includes GET and HEAD operations plus manually reviewed read-only POST lookups. It cannot place orders, send mail, or change your skill queue. Character tools manage local authorisation and selection. Map rendering saves generated files on your machine.

What is stored on my machine?+

The server caches public EVE static data and saves generated maps locally. Character refresh credentials are stored in a local JSON file protected by filesystem permissions; the file is not encrypted. EVE access tokens stay in server memory. See the authentication guide for storage and configuration details.

Do I need to authorise a character?+

Only for protected EVE data. Public market and universe queries work without EVE character credentials. Map rendering needs no EVE login and makes no ESI calls. Use EVE SSO when you want to read your character’s protected data.

How do I view a generated map?+

Read the original SVG through its MCP resource URI. Generated maps and manifests are stored locally and expire after seven days or earlier storage eviction; render again if unavailable. Your MCP client needs to support resource reads to retrieve the original.

A requested PNG preview is included when the host adapter succeeds. Preview failures preserve the SVG with an explicit warning; inline display depends on your MCP client. The map visualizes supplied plans, not live travel safety.

How fresh is the data?+

ESI controls when its data updates; responses expose available cache and pagination metadata. Skill tools load static data automatically and report its build and freshness. The local server warms its skill cache at startup and checks for updates on use. Data is not a real-time view of the game.

What can a skill plan tell me?+

It maps prerequisites, removes completed permanent skill levels, and produces ordered training text with estimated missing skill points. It does not calculate training duration, fitting viability, or clone eligibility, and does not edit your in-game queue.

What about corporation data?+

Corporation reads are available through the ESI catalog where supported. They use an approved acting character with the required scopes; ESI enforces in-game roles and permissions.

Where can I find the modules?+

Install the eve-online-mcp package from npm to run the modules together as a local MCP server. The GitHub repository contains the source, setup instructions, and configuration options. The project is licensed under AGPL-3.0-only.

Can I use more than one character?+

Yes. Authorise each character through EVE SSO, then use list_eve_characters to see saved characters and select_eve_character to save a default across sessions. Requests for a specific character use that character’s credentials.
